# Command: `ekapkgs fuse`

Mounts a FUSE filesystem at `/usr/lib` (configurable) to serve shared libraries on-demand from a Nix binary cache. Designed for use with nix-ld so unpatched binaries with `/usr/lib` on their RPATH can transparently load Nix-provided libraries.

## Subcommands

- `mount` — mount the FUSE filesystem (requires root for `allow_other`)
- `unmount` — unmount the FUSE filesystem
- `status` — check if the FUSE mount is active

## Architecture

### Soname index

A ZSTD-compressed JSON index (`sonames.json.zst`) maps sonames to Nix packages. Generated by eka-ci and fetched via the same index infrastructure as `ekapkgs search` (shared helpers in `commands/search.rs`). Index entries include package name, store path, relative file path, and `meta.priority` for conflict resolution.

- **Types:** `SonameEntry`, `SonameIndex` in `src/soname_index.rs`
- **Priority dedup:** when multiple packages provide the same soname, lowest `meta.priority` wins
- **Storage:** `~/.cache/ekapkgs/indexes/sonames.json.zst`

### FUSE filesystem (`LibFs`)

- All sonames get pre-assigned inodes at mount time (inode 1 = root, 2..N = sonames)
- Index is behind `Arc<RwLock<SonameIndex>>` to support future SIGHUP-based live reload
- `open()` is the download trigger — checks if the store path exists, downloads via the existing 3-tier negotiate flow if not
- `read()` uses `std::os::unix::fs::FileExt::read_at()` for zero-copy positional reads (no `unsafe`)
- Per-store-hash `Mutex` prevents duplicate concurrent downloads for the same package
- A persistent `tokio::runtime::Runtime` handles async downloads inside FUSE callbacks

### On-demand download flow

1. FUSE `open()` receives inode → resolves to soname → looks up `SonameEntry`
2. Checks if `/nix/store/{hash}-.../lib/libfoo.so.x.y.z` exists (fast path)
3. If missing: acquires per-hash download lock, calls `negotiate()` + `import_with_fallback()` (3-tier: CAS chunks → gRPC streaming → HTTP batch)
4. Opens the real file, returns file handle

### Dependencies on existing code

- `commands/search.rs` — `pub(crate)` index cache helpers (`read_index`, `try_download_index`)
- `prefetch.rs` — `pub(crate) import_with_fallback()` for 3-tier download
- `negotiate.rs` — `negotiate()` for cache negotiation
- `ekapkgs_nix::store::store_path_hash()` — extract hash from store paths

### Update strategy

Phase 1: remount on update (`unmount` + `mount` after `system switch`).
Phase 2 (future): SIGHUP reload with kernel cache invalidation via `fuser::notify_inval_entry`.
